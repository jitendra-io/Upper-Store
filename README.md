**Upper Store** is a full-stack digital distribution platform engineered to deliver elite software applications, games, and developer tools. Designed with a luxury dark aesthetic, interactive particle physics, and robust cloud services, Upper Store delivers a smooth software discovery and download experience.

---

## ✨ Key Features

- 💎 **Luxury Glassmorphism UI**: High-end noir & gold aesthetic powered by responsive CSS and Outfit typography.
- 🌌 **Interactive HTML5 Canvas Physics**: Free-floating 150-particle constellation with dynamic cursor repulsion.
- 📦 **Multi-Format Software Distribution**: Native support for Android APKs (`.apk`), Windows Executables (`.exe`), and Zip Archives (`.zip`).
- 🚀 **Automated GitHub Releases Pipeline**: Direct CDN asset uploads and zero-rate-limit binary delivery via GitHub Releases API.
- 🛡️ **Role-Based Admin Control Center**:
  - Live inventory management (Add, Edit, Delete products)
  - Real-time download metrics & Firestore analytics
  - Customer inbox & contact management
  - User ban & appeal moderation system with 7-day rate-limiting
- 💬 **Ratings & Community Reviews**: 5-star ratings, verified downloader review eligibility, and interactive moderation.
- 🔒 **Firebase Authentication**: Seamless Google Sign-In with popup chooser and secure JWT admin session controls.
- 🌐 **Automated CI/CD**: Zero-downtime static deployment configured for GitHub Pages with SPA 404 routing.

---

## 🛠️ Technology Stack

| Component | Technologies |
|---|---|
| **Frontend** | React 19, Vite, React Router v6, HTML5 Canvas, Vanilla CSS |
| **Backend** | Node.js, Express, Multer, ImageKit SDK, Nodemailer |
| **Database & Auth** | Google Firebase Firestore, Firebase Admin SDK, Firebase Auth |
| **Binary Delivery** | GitHub Releases API REST CDN |
| **CI/CD** | GitHub Actions (`deploy.yml`) |
